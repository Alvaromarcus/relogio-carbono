## Sobre os dados de origem

Os dados brutos vêm do **ONS — Operador Nacional do Sistema Elétrico**, pelo
[Portal de Dados Abertos](https://dados.ons.org.br/dataset/balanco-energia-subsistema),
sob Creative Commons Attribution. A licença de origem continua valendo: quem reutilizar
o `sin.json` deve creditar o ONS como fonte dos dados, além de creditar este projeto pelo
tratamento e pelo cálculo. As duas atribuições são cumulativas, não alternativas.

Os fatores de emissão são do [IPCC AR5, WG3, Annex III, Table A.III.2](https://www.ipcc.ch/site/assets/uploads/2018/02/ipcc_wg3_ar5_annex-iii.pdf)
e não são cobertos por esta licença — pertencem ao IPCC e seguem os termos dele.
